# Repository curation report

Date: 2026-07-15

Branch: `chore/repository-curation`

Base commit: `7704069388218f6b0a6a90bb85033bcdc61a0c0d`

This report records the changes made after the standalone
[repository audit](repository-audit.md). The work was intentionally
conservative: notebook source and useful analytical output were preserved
unless a change was mechanical, a reference was demonstrably stale, or an
artefact was clearly regenerated by retained code.

## Generated artefacts removed

Six files were deleted after confirming that retained notebooks contain the
generation steps and no current code loads the saved copies:

- `Python/projects/ames_house/ames_house_price_model.joblib`;
- `Python/projects/vehicles/vehicle_price_model_v1.pkl`;
- `Python/projects/book_recommender/data/chroma_books/69572dcb-7eb0-49c4-a6a7-608f5ab454e0/data_level0.bin`;
- the corresponding Chroma `header.bin`, `length.bin` and `link_lists.bin`.

The source book data and derived text/CSV files were preserved because the
future status of the recommender is unresolved. The Chinook SQLite database,
an avocado pickle dataset and three archived challenge fixtures were also
preserved as intentional inputs rather than treated as caches.

## Ignore policy

The previous broad template was replaced with a repository-specific
`.gitignore` covering:

- Python environments, bytecode, test/type/lint caches and build output;
- Jupyter transient state;
- local environment/credential files;
- Chroma/vector indexes and transient SQLite state;
- generated model artefacts;
- editor, operating-system, log and scratch files.

Explicit exceptions retain the avocado pickle dataset and archived Reboot
fixtures. CSV, JSON, spreadsheet, image and general `data/` paths are not
blanket-ignored. A final `git ls-files -ci --exclude-standard` check found no
tracked files accidentally covered by the policy.

## Notebook cleanup

All 84 notebooks were parsed before and after editing. Sixty notebooks had one
or more transient items removed. The cleanup:

- cleared 25 output objects: five errors, 20 containing local user paths and
  four containing rendered email fields, with overlap between categories;
- reset execution counts in 22 affected cells;
- removed root Colab, accelerator and editor metadata;
- removed cell-level Colab, VS Code, scheduling, timestamp and output-ID
  metadata;
- removed 711 Data Wrangler MIME payloads in total: 707 directly and four as
  part of cleared outputs;
- removed 10 Colab-specific MIME payloads;
- preserved cell source, order, IDs, tags and meaningful collapse/folding
  metadata;
- preserved 2,047 useful output objects, including plots, tables and model
  summaries;
- preserved non-sequential execution counts in 17 notebooks as historical
  state;
- did not globally execute any notebook.

One unambiguous pandas exercise typo was corrected from invalid indexing syntax
to `temperatures.set_index("city")`. An unfinished bike-sharing assignment was
not guessed; it is documented for [human review](human_review.md).

## Reference and helper repairs

References were updated only where the current equivalent was demonstrable:

- predecessor repository names were changed to `data-science-notebooks` for
  files that exist in the current tree;
- repository-relative raw paths were updated after the supervised,
  unsupervised, Telco, EDA, Matplotlib and archive moves;
- the heart-disease helper URL now points to the tracked
  `eda_modules/helpers/missing.py`, whose public function matches the call;
- the archived path exercise now uses its relative fixture path and resolves
  it at runtime;
- navigation links were updated to the curated names;
- one unused local variable in `Python/helpers/plot_seaborn.py` was removed
  after Ruff confirmed it had no reader.

Sixty parsed raw GitHub URLs point into the current repository, and every one
maps to a tracked path. One predecessor URL remains deliberately: the missing
air-quality CSV has no local equivalent and the URL returned HTTP 404 during
validation. Replacing it without an authoritative source would invent
provenance.

### Security and privacy

A redacted current-tree scan checked for private-key headers and common AWS,
GitHub, OpenAI, Google, Slack, JWT and credential-assignment shapes. It did not
print candidate values. The only token-shaped matches were confirmed as
scikit-learn rendered HTML element IDs across ten notebooks, not credentials.

Dedicated `gitleaks`, `detect-secrets` and `trufflehog` executables were not
available, so this is a reasonable fallback scan rather than a certification.
Rendered output cells containing email fields were cleared, but tracked source
datasets still contain email-like contact fields; their necessity and source
terms require human review.
